# 高级单元格配置归属整理与优化验收

日期：2026-10-29。对应整改清单第54节。状态：已实现并按本文范围验收。

后续入口调整：生成表头及指标标签改为双击直接编辑文字，见[第57节实施验收](generated-label-editing-implementation-and-acceptance-2026-10-29.md)；第58节移除“字段信息”，第59节移除独立“整行样式”页签。条件规则中的单格/整行样式动作继续保留，其余配置分类保持本节约定。

普通外观归Excel工具栏，高级配置集中处理报表业务语义。维度、指标、静态文本及其余角色按适用能力提供属性，不增加旧配置迁移、兼容分支或双写。

## 2. 各角色最终页签

| 角色 | 页签 | 专属及公共属性 |
| --- | --- | --- |
| 分类/时间维度 | 维度设置、条件规则、整行样式、动态合并、字段信息 | 维度方向和时间分组说明；空值、条件、整行样式、分组/同值合并；无聚合及缩放 |
| 统计指标 | 指标设置、条件规则、整行样式、动态合并、字段信息 | 可编辑聚合同步左侧及总计；空值、缩放、条件、整行样式和适用合并 |
| 明细列 | 明细设置、条件规则、整行样式、动态合并、字段信息 | 保持逐条明细，不提供聚合；数值明细可以缩放 |
| 公式结果 | 结果设置、条件规则、整行样式、字段信息 | 查看原公式，F2编辑工作表公式；按实际结果类型提供缩放，不能切换为SUM/AVG指标 |
| 派生总计/小计 | 汇总设置、条件规则、整行样式、动态合并、字段信息 | 聚合继承原指标；空值、缩放、条件、整行样式和适用合并 |
| 静态文本/固定值 | 内容、合并与范围 | 文本、范围跟随、重复和位置、合并意图；无样式/条件/统计页 |
| 生成表头 | 字段信息 | 内容和层级由面板生成，只读；外观和固定选区合并用工具栏 |
| 空白格 | 不打开 | 0、false及暂时无结果的有效绑定/公式仍可打开；普通空格输入文字后可配置 |

静态范围仍可默认居中，工具栏显式对齐继续优先。取消合并后长标题受当前单格宽度和截断设置约束；范围跟随规则保留，不代表仍占据一个横向合并区。

## 3. 保留业务属性的原因

### 普通外观、整行规则、条件动作

工具栏编辑普通单格/选区外观。整行基础样式按源格展开后的行和动态列宽应用；条件样式要在条件命中后执行。因此高级配置仍在这两类业务动作中提供配色、字号、对齐等控件，不再提供独立普通样式页。

覆盖顺序保持：**基础外观→整行基础样式→单格普通覆盖→条件整行样式→条件单格样式**。Excel格式颜色按既有规则在条件动作前生效；未完整覆盖的跨行合并格保留原样式。

### 缩放和Excel数字格式

模式`0.0"千件"`负责精度和单位文字，业务倍率1000负责将显示输入除以1000。原值600仍是600，显示`0.6千件`。保留缩放可以支持“万”等业务倍率，不改变聚合和公式引用。

一次工具栏格式修改由新模式串完整接管前后缀、零值、负数和日期等普通显示，避免再叠加旧的同类格式属性；业务缩放与空值占位独立保留。这是新格式编辑的写入语义，不扫描或迁移旧配置。

### 固定合并和动态意图

工具栏合并处理当前选区，动态合并/范围跟随表达数据变化后的意图。将分组覆盖、同值合并和范围跟随都改成一次选区操作，会丢失新增成员或列后的业务边界，因此继续保留高级业务配置。

## 4. 实现落点

1. `cellCapabilities.ts`集中定义高级可编辑格式白名单、条件和整行能力，以及角色页签。角色取自绑定，值类型只用于判断缩放和比较方式。
2. `CellAdvancedSettings.tsx`按能力生成页面，移除普通样式、数字预设、精度、千分位、单位、负数、零值及日期格式的重复控件；保留指标口径、业务缩放和公共空值文字。表头只读。
3. `advancedCellState.ts`只提交实际修改，提交端拒绝普通格式/单格样式修改，也拒绝借部分formatOptions删除工具栏模式；绑定、父格、位置、展开和公式仍受保护。
4. 整行规则独立使用`scope: row`，按源格生成规则ID。明确读取row规则，避免与同源高优先级template-cell普通覆盖混淆。停用保存`enabled: false`，保留颜色、重置等参数；再启用复用ID和优先级。
5. 普通工具栏样式、整行样式和presentationRules分别保存。改变口径时允许自身规则目标同步重绑，不允许借高级提交修改其他源格的整行规则或增删普通样式。
6. `StyleEffectEditor`一套实现供两处使用：整行基础样式固定作用范围；条件动作保留单格/整行选择及调色盘。
7. `numberFormatOptions`使工具栏模式统一接管普通显示，业务缩放和空值独立。沿原有源快照→展开→publication→VTable运行，没有另设演示链路。

`AdvancedCellDraft.rowStyleEnabled`是草稿状态，保存使用既有StyleRule.enabled。前文保留普通样式/高级数字格式入口的约定，以本节替代。

## 9. 类型与最小提交约定

本节合并原第47节独立说明中仍有效的约定。其历史验收结果、数据及源码指纹保留在整改清单第47～51节和对应verification目录中。

| 条件左值类型 | 适用比较 |
| --- | --- |
| 文本 | 相等、不等、包含、开头、结尾、集合、空值 |
| 数值 | 大小、闭区间、相等、集合、空值 |
| 日期 | 早于、不晚于、晚于、不早于、闭区间、相等、集合、空值 |
| 布尔 | 相等、集合、空值，使用是/否输入 |
| 暂无结果 | 相等、集合、空值，保留有效配置等待数据恢复 |

条件按实际左值判断类型。文本维度中引用数值聚合时，提供数值比较；同字段的文本维度与COUNT结果按勾选角色检查，不能盲目按字段名混用类型。集合比较使用显式值列表，比较节点记录valueType，日期字面量带日期标记。

日期比较支持ISO日期/时间、带时区的ISO时间，以及默认年、月、季度、周、自定义周期标签的起点；无时区的日历文字按统一UTC坐标比较，不解析任意自定义显示文案。日期、左右类型、区间顺序和运算符在保存及编译时共同检查。

界面通过createAdvancedCellDraft、buildAdvancedCellUpdate、validateAdvancedCellUpdate共用最小更新：无修改应用不产生空规则，不写入默认精度；修改空值等业务属性只合并该项。字段身份、位置、父格、展开结构及原公式不被高级配置改写；生成文字编辑按第57节单独处理。

文本编号0012、0000和文本0保持文本，静态false保持布尔值。口径更新由changeMetricAggregation同步指标和派生总计，自身样式及条件目标重新绑定，同字段维度不改成聚合；数据刷新和程序投影不制造用户历史。
