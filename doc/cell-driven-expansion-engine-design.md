# 模式三受控模板的展开约定

维护日期：2026-10-28。原文件中的模式二自由单元格配置、多区域自由排布及旧配置迁移方案已停止采用。当前产品仅保留模式一图表和模式三表格；本文件保留共享展开模型的有效约定。产品边界、实现及最新验收见[模式二下线记录](mode2-retirement-and-guided-editing-2026-10-28.md)。

## 1. 配置源与生成职责

模式三通过面板选择数据源、时间维度、多级行列分类、指标及聚合。`compilePanelToCellTemplate`生成数据区原型，`hybridConfig`保存明确行列轴和面板恢复状态。用户不通过移动数据格或编辑父格来改变报表结构。

`CellTemplateDocumentV1`仍是共享内部源模型，名字保留不代表兼容已退役模式二。父格、扩展方向、区域、重复粒度及指标身份继续服务编译，但由生成器及受控高级设置维护。

标题、静态文本、工作表公式、样式、条件、范围跟随、合并与取消例外和已有覆盖保存在源模板中。Univer工作簿及某次预览的坐标是派生投影，不能替代权威源。

## 2. 数据展开

行轴与列轴均可以同时包含时间和多级分类；顺序按面板保存的轴描述执行。展开后每个实例绑定完整区域、源格、行列成员路径、业务角色及指标身份。

交叉格按行列完整成员路径定位事实交集，再执行聚合或业务公式。均值和比率必须在实际事实范围计算，不对显示文案或已聚合均值再次求和。

分组、透视表头、小计和总计是不同业务角色。总计标签不是普通分类值，也不与同名成员共用身份。空交集、空数据、字段不匹配及不支持的结构按现有校验器和编译器的诊断处理。

模板位置和展开结果位置不要求一一对应。数据增长、指标数变化及多级分组会改变实际footprint；静态范围及合并应从业务范围求解，不能硬编码首行、第二行或固定列数。

## 3. 身份与数据变化

规则定位使用区域、源格、字段、数据角色、操作、指标及完整成员路径，不能使用当前行号或显示文字作为唯一身份。数字1、字符串1、空值和总计角色不得混为一类。

事实新增、删除、排序或透视列变化时，重新展开并解析源规则。当前不存在的字段/成员规则可以休眠，重新出现后按原身份恢复；不能把休眠的明细规则套给同名度量。

已有实例覆盖、合并及取消例外继续执行原身份和数据版本校验。模式三不开放任意数据格改值作为新的配置方式；已有源规则不因本轮下线或保护策略被批量清除。

## 4. 允许编辑的范围

数据区原型包含生成表头、维度、指标及内部空白。直接输入、粘贴、清空、改公式和破坏字段行列的操作被阻止；父格与扩展方向在高级设置中只读。模板态仍可配置格式、样式、条件、备注说明及受控合并。

数据区外静态内容可编辑，支持静态公式、原生排版及范围跟随。安全插入整行/列可整体移动数据块，不能在原型内部拆开生成结构。动态预览的数据与样式只读，允许既有合并/取消意图操作。

命令保护、实际粘贴范围和保存快照共同保证生成内容不被覆盖。程序投影及源历史回放必须带事务标记；原生公式结果回写和合并样式补丁按明确SDK身份单独处理。

## 5. 发布与展示

`compileCellReport`依次校验、展开、计算、应用条件、静态范围、样式及合并，生成中性的`PublishedReport`。原值、基础格式文本及最终显示文本分离。文本替换或合并不改变底层计算值。

模式三保存源模板、publication及版本戳；重开恢复面板和源规则。数据版本改变后重新编译，VTable读取新发布结果。展示态不实例化Univer，也不自行推断相邻同值合并。

## 6. 扩展与验收要求

新增报表形态应增加模式三受控配置、生成适配、身份规则及测试，不重新开放自由数据区域、模式二或模式间转换。每项扩展需验收模板设计、动态预览、保存重开和VTable，并覆盖数据增删、排序、分组/透视列变化、取消规则及撤销重做。

多区域自由布局、任意父格编辑、专家脚本与完整Excel操作不是当前产品承诺。下钻仍按[整改清单第44节](univer-implementation-issues-and-remediation.md#44-模式三单元格交互与下钻待办2026-10-27)登记，尚未实施。
