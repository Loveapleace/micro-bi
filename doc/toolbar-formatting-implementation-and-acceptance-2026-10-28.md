# Excel工具栏样式与数字格式实施验收

日期：2026-10-28。对应整改清单第52节。状态：已实现并通过本节列出的验收。静态高级配置仍只有“内容”和“合并与范围”，不增加旧配置迁移、双写或历史结构兜底。

2026-10-29更新：高级配置中的普通样式及数字/日期格式重复入口已移除，业务缩放、空值、整行基础样式及条件动作另行保留；一次新工具栏模式修改统一接管普通数字显示。当前归属与回归结果见[第54节实施验收](advanced-cell-settings-ownership-and-acceptance-2026-10-29.md)。

## 1. 操作边界

| 操作 | 当前行为 |
| --- | --- |
| 字体、字号、粗体、斜体、文字色、背景色、水平/垂直对齐 | 工具栏编辑，统一保存到源格样式，按源格身份应用于展开实例 |
| 下划线、删除线 | 支持设置、关闭、预览、保存重开及VTable显示 |
| 四边边框 | 分别保存颜色、线型和粗细；支持细/中/粗、点线、虚线、点划线及双线；取消边框保存为明确的none |
| 自动换行、截断 | 支持；不换行统一为截断，VTable不加省略号 |
| 百分比、货币、小数位、分组、科学计数、分数、日期及自定义格式 | 保存Excel模式串，预览与VTable使用同一纯格式化逻辑；原数值及公式不被替换成显示文字 |
| 清除格式 | 重置普通外观、边框及数字格式；保持内容、绑定、聚合、公式、动态范围和业务条件规则 |
| 格式刷 | 复制源格的外观及数字格式；不复制数值、字段绑定或公式；可用于数据区外观 |
| 撤销、重做 | 普通样式、数字格式、边框、清除及格式刷共用源历史 |
| 文本旋转、缩小字体填充 | 工具栏隐藏，直接命令也拒绝，避免设计态与VTable不一致 |
| 跨单元格溢出 | 从换行菜单移除；直接命令拒绝，提供原因提示 |
| 对角线边框 | 命令拒绝并提示，当前不发布为VTable效果；四条外边框继续可用 |

清除格式后，指标的业务条件规则仍可能再次产生告警样式，这是既定的分层行为。清除外观不能改变聚合或取消告警规则。静态格不提供条件规则，模板校验拒绝静态条件目标，也不再暗中消费这类规则。

## 2. 新样式与格式结构

`CellStyleDefinition`、`PublishedCellStyle`共用四边边框对象：每条边包含style与color，替代原来“边是否存在+一个统一颜色”的表达。新增源下划线、删除线，以及常规对齐general；常规对齐在VTable按原始类型区分文本左对齐、数值右对齐。

```ts
style: {
  underline: true,
  strikethrough: false,
  textAlign: 'general',
  border: {
    top: { style: 'double', color: '#CF1322' },
    right: { style: 'thick', color: '#1677FF' },
    bottom: { style: 'dashed', color: '#389E0D' },
    left: { style: 'none' }
  }
}
formatOptions: {
  numberFormat: '#,##0.000"件"'
}
```

工具栏格式保存为`formatOptions.numberFormat`。数字格式只负责显示；字段、聚合和原值独立保存。格式模式经长度和语法校验，非法配置阻止发布。`General`表示明确清除数字格式，不会偷偷恢复面板生成的两位小数。

高级显示设置和左侧预设共用同一结构：明确修改预设、精度、分隔或日期显示时，移除原模式串，使用本次设置；通过工具栏再次设置模式串时，以新模式串为准。缩放和单位等业务属性保持；“显示数值”条件按模式串的倍率与业务缩放取值，不解析带单位的文字。小数位允许0～20。

新增固定版本`numfmt@4.1.1`（MIT），提供纯JavaScript的Excel格式计算，支持ESM/CJS；它不引入Univer或DOM。来源：[numfmt项目](https://github.com/borgar/numfmt)。时间分组标签按周期起点转换为显示日期，保持原分组成员和排序键。字符串编号、布尔值不因选择数字格式变成数值。

格式颜色在普通样式之后、条件样式之前执行。例如负数格式中的Red优先于普通字体色，命中的条件告警仍可覆盖它。

## 3. 保存与渲染链路

1. 工具栏原生命令修改工作簿，内容保护允许纯样式命令，继续拒绝数据区改值。
2. `syncWorkbookToTemplate`读取样式字典及n.pattern，与上次实际投影按统一默认值比较；未修改直接保存不生成默认覆盖。
3. 属性被移除时生成明确的false、none、General或无填充意图，避免旧值从基础样式或面板重新出现。
4. 面板与自定义源格的合并保留最新原生格式，不再被上次extras中的内容覆盖。
5. 展开器输出原值、显示文字和中性样式；Univer只回显该投影，VTable读取同一个publication。
6. VTable四边使用独立颜色/宽度/虚线数组；双线通过原边框加一条内侧线绘制。共享样式转换也用于静态范围和独立工作簿快照编译。

双线扩展仅挂到有双线的列/合并区域，没有双线的单元格不创建空的自定义绘制容器。验收还复现配置弹窗开关后首列“原值及样式存在但文字未绘制”：单纯重绘没有恢复，重建单元格可恢复。ReportTableView在布局属性提交及容器尺寸变化后同步尺寸并重建可见单元格，不修改数据或源配置。连续三轮打开/取消配置后首列和表头完整，恢复截图已覆盖此场景。

命令历史覆盖数字格式、下划线/删除线、边框、清除和格式刷。同一同步调用中的“新建值+紧接着设置格式”在下一任务边界一次捕获，不再逐条setState触发投影，防止值更新先重绘、覆盖后续格式。普通用户操作仍能分别撤销、重做。

## 4. 实际入口验收

使用`http://localhost:5174/`原模式三配置入口，独立浏览器上下文和存储。没有修改用户浏览器原看板或事实文件。

| 场景 | 结果 |
| --- | --- |
| 静态标题 | 下划线、删除线、字号18和紫色进入预览与VTable；高级弹窗只有两个页签 |
| 百分比、小数位 | 交付原值600仍是600，测试显示60000.0%；增加小数位后撤销为0%，重做恢复0.0% |
| 货币 | 缺陷指标显示货币格式，原值、SUM和总计不被显示文字替换 |
| 四边与双线 | 源指标分别设置红双线、蓝粗线、绿虚线和橙细线，所有展开实例和保存重开保持 |
| 清除与撤销 | 清除后字号11、黑色、常规对齐、无装饰、无边框、General；撤销恢复百分比及四边 |
| 格式刷 | 从标题刷到A2，再输入“格式刷说明”，字号/颜色/下划线/删除线保留，未复制标题文字 |
| 日期维度 | 原值2026-08-01保留，显示2026年08月01日，原五个日成员保持 |
| 新建值紧接设置格式 | 同步写入46235并设置日期后显示2026-08-01；12345.678显示12,345.678件，重开保持 |
| 公式 | 原SUM(C4:D4)保持，基线结果1350，显示1,350.000 |
| 无修改保存 | 新开模式三直接保存，样式规则0条，不注入数字格式覆盖 |
| 弹窗开关后绘制 | 连续三轮打开/取消配置，首列文字、表头、双线与指标文字均完整，不再只保留背景 |
| 不支持的操作 | 旋转、缩小入口隐藏，菜单无溢出；直接发起溢出/旋转/对角线命令返回false并提示 |

表中的百分比刻意用于验证原值与显示倍率，并非修改用户的实际业务看板。字号、线条、数字格式主操作经真实工具栏执行；分边颜色/线型和自定义模式串使用同一个原生命令链的公共Facade设置，范围由原设计器选中。

普通Excel坐标公式按当前展开坐标求值，新增分组后C4、D4可能对应其他切片。实际测试SUM(C4:D4)在新增组后为0，删除首组后为2700，恢复后为1350；公式文字始终不变。需要固定业务口径时使用业务公式，不能把显示格式当成语义引用机制。
