# 生成表头及指标标签直接编辑

日期：2026-10-29。对应整改清单第57节。已实现并验收。本次改变生成文字标签的编辑行为，其余高级配置界面沿用第54节。

## 1. 操作约定

| 对象 | 模板设计态双击 | 保存含义 |
| --- | --- | --- |
| 生成表头，如“指标名称”“承制车间”“行总计” | 原生文字编辑，不弹高级配置 | 保存该标签的自定义文字 |
| 面板生成的指标标签，如“交付件数” | 原生文字编辑，不弹高级配置 | 按源标签身份覆盖，动态展开后的各实例共用 |
| 真正绑定的维度、指标和公式结果 | 按原角色打开高级配置 | 字段、父格、统计口径等仍受既有规则管理 |
| 报表标题和自定义静态内容 | 保留内容/合并与范围入口；F2继续可用 | 原静态内容及范围配置保持 |
| 数据区外空白格 | 原生编辑，沿用第56节修复 | 新增静态内容 |
| 数据区内部空隙、动态预览内容 | 保持保护 | 不允许将受控数据改成任意文本 |

允许编辑预设文字，不代表修改数据字段：将“承制车间”改成“责任车间”后，实际分组仍使用`workshop`。将“交付件数”标签改成“交付数量（件）”后，计算仍引用原指标字段和口径。标签本身保持literal，不转换为字段或公式。

此约定替代第54节“生成表头只读查看”的入口决定，不恢复已撤回的信息精简界面。

## 2. 实现

1. `guidedSource.ts`通过面板归属和literal内容识别可编辑生成文字。标题保留独立内容/范围配置，避免失去静态范围入口。
2. `cellCapabilities.ts`让这类文字不再进入高级配置；第56节的双击桥接将未接管的操作交回Univer原生输入。
3. `guidedEditing.ts`区分区域结构保护和内容保护。区域边界仍保护插入、删除及移动结构，文字标签允许原生编辑、清空和适用的粘贴；包含数据值或内部空隙的混合写入仍整体拒绝。
4. 公式和共享公式写入不能把标签变成计算格，预览继续只读。样式、合并保护和真正数据格的写入防线保持。
5. `syncWorkbookToTemplate.ts`捕获文字并保存`literalOverride: true`，保留`panelOwner`、源格ID、语义身份和父格。现有合成逻辑按身份应用覆盖，不靠显示文字或固定坐标重新绑定。
6. 多行原生编辑可能使用文档数据保存，读取时只去掉SDK固定的末尾段落结束符，保留用户的换行和空格。
7. SDK清空内容后，完整工作表快照可能只剩样式、没有v和投影元数据。完整快照将这种情况视为空文案覆盖；部分纯样式快照则保留原文案，避免清空后被默认标签恢复或样式修改误删文字。

没有新增旧配置迁移、转换或双写。用户文字与字段结构分开保存，面板重生成仍维护字段和父格，文字覆盖沿原身份迁移。

## 3. 真实入口验收

在5174实际模式三预设报表的独立浏览器上下文操作，未改用户原看板存储。

| 用例 | 结果 |
| --- | --- |
| 直接双击 | B3“指标名称”触发BeforeSheetEditStart和SheetEditStarted，未取消原生编辑，未弹高级配置 |
| 改文案 | B3→统计项目，A3→责任车间，B4指标标签→交付数量（件），D3→合计 |
| 撤销/重做 | 统计项目可撤销回指标名称，再重做恢复 |
| 连续编辑 | 保存重开后将统计项目改为经营指标，再改回统计项目，最终值正确 |
| 清空保存 | Delete清空合计后，保存源保留literalOverride=true且value=null；重开仍为空，可双击直接输入合计 |
| 模板位移 | 新增加工工件名称行维度，统计项目由B3移到C3、指标标签由B4移到C4，四条自定义文字保持；移除该维度后恢复原位置及文案 |
| 原配置入口 | 真实指标C4仍有5个适用页签，标题A1仍有内容/合并与范围两个页签 |
| 动态预览 | 自定义指标标签随3个车间分组重复；600、750、1200、1500等原指标数值正常 |
| 保存重开及刷新 | 四处文字、归属、父格及literalOverride保留，刷新后模板源逐字相同 |
| VTable | 显示责任车间、统计项目、交付数量（件）、合计；指标数据和原有合并正常 |

通过真实注册表执行13→新增车间和日期14→逆序14→删首车间7→清空0→恢复13。各阶段模板源逐字不变，正式publication的工作表和样式与实际编译器预期一致；新增原值2400正常。空数据没有指标标签实例，但四条文字覆盖仍保留；恢复后指标标签重新随分组出现。
