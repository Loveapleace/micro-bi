## 2. 可直接使用的示例

主应用地址：`http://localhost:5174/`。

入口：**新建分析看板右侧下拉 → 示例：车间交付与质量交叉报表**。该入口打开原主应用中的单元格设计弹窗；点击保存后，新增原看板卡片。卡片的“配置”按钮重新打开同一模板。新建主按钮继续打开原配置面板。

模板文件：[workshop-delivery-quality.json](../examples/cell-reports/workshop-delivery-quality.json)。主应用工厂：[cellReportExamples.ts](../../dynamic-data-test/src/constants/cellReportExamples.ts)。二者共用同一份 JSON，每次创建仅生成独立文档 ID，模板单元格 ID 保持稳定。

| 配置 | 示例内容 |
| --- | --- |
| 数据集 | `industrial_lifecycle_orders`，现有工单数据，共 13 条；没有新增或替换生产模拟数据源 |
| 布局 | 双向交叉透视表；指标纵向展开，可在工具栏切换横向 |
| 行维度 | `workshop`，承制车间 |
| 列维度 | `plan_start_time`，按日分桶 |
| 度量一 | `SUM(output_qty)`，交付件数，千分位与两位小数、蓝色、右对齐 |
| 度量二 | `SUM(defect_count)`，缺陷件数 |
| 度量三 | `IF([SUM(output_qty)] > 0, [SUM(defect_count)] / [SUM(output_qty)], 0)`，汇总级公式，内部精度 6，显示为两位百分比 |
| 父格 | 度量引用 `workshop` 为行父格、`plan-date` 为列父格；当前标准矩阵由区域行列轴执行 |
| 自由内容 | 第 1 行标题，第 2 行说明，显式标题/说明合并 |
| 数据锚点 | 第 4 行第 1 列，即 `{row:3,column:0}`；不覆盖上方标题 |
| 列宽 | 第 1 列 180，第 2 列 140 |
| 保存 | `authoringMode:'cell'` 与 `CellSavedReportBundleV1`，包括模板、publication、stamp；宿主 localStorage 持久化 |
| 展示 | 原主应用 VTable 报表卡片，单元格报表不提供无数据映射的图表切换 |

此示例用于验证侧栏及高级设置所表达的模板规则。不要用它证明 F2、合并工具栏、条件格式或实例覆盖已经完整实现。

### 2.1 基准结果

| 车间 | 交付件数 | 缺陷件数 | 加权缺陷率 |
| --- | ---: | ---: | ---: |
| 1号五轴切削车间 | 4,400.00 | 105 | 2.39% |
| 2号重型冲压车间 | 4,550.00 | 99 | 2.18% |
| 3号智能装配车间 | 1,900.00 | 33 | 1.74% |
| 总计 | **10,850.00** | **237** | **2.18%** |

全局缺陷率从 237 / 10850 重新计算，不是车间百分比的平均数。日期从 2026-08-01 至 2026-08-05。无事实的交叉格显示 `-`，不把它当成丢值问题。

### 2.2 手动操作步骤

1. 从示例菜单打开设计器，确认左侧 9 个字段及顶部 13 行数据。
2. 单击 C5，右侧应定位 R5C3，绑定 `output_qty`、求和、跟随父格；更改显示名称后直接点底部保存，不能要求先点“应用配置”才不丢草稿。
3. 双击 C5，打开一次高级设置；查看行/列父格，选择千分位、加粗、右对齐，确认。
4. 切换动态展开预览，核对日期文字、交付件数与百分比。切回模板后，不应残留上次展开的成员格。
5. 保存，在原看板查看新卡片，选中报表按 Ctrl+A、Ctrl+C，可粘贴核对 VTable 实际显示结果。
6. 刷新页面，点击该卡片“配置”，确认仍进入单元格方式；原面板条目继续打开原方式。
7. 可在报表布局切换分组，在指标方向切换横/纵；如需多级分组，将日期格角色调整为行维度并设置父格，再查看结果。复杂父格规则仍须按第 5 节整改后验收。

## 4. 动态数据的浏览器实测

本轮在保持页面打开、没有重新编辑和保存报表的情况下，临时修改本地 mock 源触发 Vite 热更新及注册表更新，再核对原 VTable 卡片。此证据覆盖主应用静态注册数据变更通道，**不等同于异步远程推送、乱序请求或 WebSocket 通道已通过**。

这组实测证明**示例的度量模板样式和格式**能在上述数据变化后生效。它没有证明针对单个业务实例的人工改值、局部样式和公式能保留，这些属于 DCR-02/09。
